## 📂 Проекты

### *AI Voice-Controlled Cooking Assistant*

Локальный ИИ-помощник, позволяющий управлять процессом приготовления еды с помощью голоса (без использования рук).

**Ключевые технологии:** Python · Распознавание речи · LLM · TTS · NLP

Проект объединяет голосовое взаимодействие, команды на естественном языке, отслеживание контекста диалога и функции работы с рецептами в едином ИИ-приложении.


### AI Mentor

Экспериментальный AI-ментор для обучения программированию, использующий технологию RAG (генерацию с опорой на поиск).

Проект исследует различные подходы к поиску информации и ответам на вопросы с помощью больших языковых моделей (LLM), включая векторный поиск, алгоритм BM25, гибридный поиск и локальные языковые модели.

Ключевые технологии: Python · LlamaIndex · LLM · RAG · Эмбеддинги · BM25 · Векторный поиск · Hugging Face · LlamaCPP · Arize Phoenix

### AI Mentor

**AI-ментор для обучения программированию на основе RAG.**

Система использует базу материалов по машинному обучению и LLM для поиска релевантной информации и формирования ответов пользователю.

Основные задачи проекта:
* подготовка и обработка документов;
* разбиение данных на чанки;
* создание embeddings;
* векторный поиск;
* BM25;
* гибридный поиск;
* генерация ответов с помощью LLM;
* работа с локальными моделями;
* исследование и оценка различных подходов к RAG.

Ключевые технологии: Python · LlamaIndex · RAG · LLM · Embeddings · BM25 · Vector Search · Hugging Face

**Ссылка:** https://github.com/VLGen/AI-mentor

### AI Voice-Controlled Cooking Assistant

**Голосовой AI-ассистент для управления процессом приготовления еды.**

Ассистент позволяет взаимодействовать с рецептом без использования рук: распознаёт голосовые команды, отслеживает состояние процесса приготовления, управляет таймерами и формирует ответы с помощью LLM.

В проекте реализованы:
* offline Speech-to-Text;
* обработка голосовых команд;
* определение окончания речи по тишине;
* управление состояниями диалога;
* сохранение контекста процесса приготовления;
* генерация ответов с помощью локальной LLM;
* Text-to-Speech;
* голосовые уведомления;
* работа с рецептами и таймерами.

Стек: Python · Vosk · Transformers · Vikhr-Qwen · pyttsx3 · Sounddevice · JSON

**Ссылка:** https://github.com/VLGen/AI-Voice-controlled-cooking-assistant
